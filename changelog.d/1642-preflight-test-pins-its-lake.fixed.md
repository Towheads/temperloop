- **`test_replay_preflight.sh` no longer reads the real host telemetry lake, so its verdict stops depending on whose machine it runs on** (#1642). The suite already pinned an empty lake inside its `run_pf` helper — and that helper's own comment named this exact hazard — but **most cases invoke the SUT directly** with their own `env` assignments, and `env VAR=v cmd` *adds* to the inherited environment rather than replacing it. So those cases read `<repo>/meta/data/raw` and derived a per-replay figure from however much replay work the host had done. Case 13 asserts `stop_reason: quota_paused` against a fixture ceiling of 1,000,000; on a host with 59 real replay records the derived figure is **1,046,509**, `ceiling_exceeded` takes precedence, and the case fails — while CI stays green, because `meta/data/raw/` is gitignored. The lake is now **exported**, so every invocation inherits it however it is called, and a new **isolation guard runs before any case** and fails immediately naming the cause, rather than surfacing as an unrelated-looking assertion failure three sections later. New case **13b** pins the precedence itself — `ceiling_exceeded` wins over `quota_paused` when both apply — since that ordering was implicit and is precisely what silently changed which condition case 13 was testing.
